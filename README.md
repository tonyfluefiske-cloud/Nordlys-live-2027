Nordlys Live 2027

Resultatservice for Nordlyscupen 18.–24. januar 2027.

Mål

* Hente resultater fra Målselv, Falken, Storfjord og Lakselvdal via MegaLink.
* Hente resultater fra Tromsø via KTS/Livevisning.
* Oppdatere sammenlagtresultatene automatisk hvert 5. minutt under cupen.
* Vise Topp 10 i hver klasse og skytterprofiler.
* Vise kampen om Nordlysbanken på 12 000 kr for klasse 3–5 og EJ.

Prosjektet er under utvikling. Testresultater er ikke offisielle.
